# 真实成功案例与测试边界

记录时间：2026-09-19；整理时间：2026-09-20。硬件：RTX 4080 16GB + 32GB 系统 RAM，Windows。全部测试在日常桌面环境下进行：后台保留浏览器、编辑器等正常使用的软件，仅排除 ComfyUI 等 GPU 重载——数字代表真实使用条件，而非静默基准环境。

## HTML / SVG 编程 Agent

在 QQZ + KVMem、64K 上下文配置、MTP2、视觉编码器 CPU 的环境下，用户要求创建一个 HTML，用 SVG 绘制鹈鹕骑自行车的 2D 动画。会话完成了单文件 HTML，并记录了 SVG XML 检查及无头 Chrome 截图验证。它是编程工具链成功案例，不是桌面视觉点击成功案例。

| 指标 | 结果 |
|---|---:|
| 成功模型调用 | 10 |
| 输出 token 合计 | 12,874 |
| 解码时间合计（先前日志审计） | 401.745 秒 |
| 加权生成速度 | 32.05 token/s |
| 最大单次输入 | 26,644 token |
| 最大单次输入 + 输出 | 26,966 token |
| 界面累计用量 | 239,728 token，显示约 240K |
| 界面任务总时长 | 约 7 分 40 秒 |

32.05 = 12,874 / 401.745，取两位小数。第一步 31.32 token/s，第二步 40.92 token/s，不能称为每一步恒定 32。任务总时长包含工具等额外开销。

64K 是配置容量；本任务实际上下文约 27K。累计 240K 是多次调用的用量累加，不是一次装入 240K。此案例也不能用于量化对比 5060 Ti：没有相同输入、版本、参数、缓存及资源状态下的受控对照。

发布时从原会话重新提取了 [每次调用的数值 usage](../evidence/agent-usage.json)，核对 10 次调用、12,874 输出和 239,728 累计 token。解码时间沿用此前本地测试报告的审计结果，未重新进行推理测速。原始对话、工具内容、路径与账号信息未发布。

## 更长上下文压力测试

已有重复源码/模拟工具结果容量测试最高完成 155,539 输入 + 35 输出 token（约 152K），该请求生成速度 17.49 token/s。超过约 64K 的已完成请求约 14–19 token/s。脱敏数值见 [capacity.json](../evidence/capacity.json)，其中 `elapsed` 是整轮秒数，`tps` 是生成速度，两者口径不同。

采样中可用系统内存最低 326.6 MiB、空闲显存最低 33 MiB，两者未必同时发生。一次大步长输入触发 `block ... has no GPU slot` / `multimodal query replay failed or cancelled`。用户要求停止后没有继续测试，因此不宣称最大稳定上下文，192K/256K 也未完成满载验证。

压力测试的输入、输出长度和资源状态不同；14–20 token/s 不应当代表所有日常 Agent 任务。没有受控复测，不能将差异简单归因于桌面程序、CPU 视觉编码器或超过 KV 预算中的任何单一因素。
